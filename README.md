# Matan Trainer

Локальный тренажёр по математическому анализу для подготовки к ИКР, ТКР и
устному экзамену. Приложение написано на Go, хранит учебный контент и прогресс
в PostgreSQL, а формулы отображает через MathJax.

> Проект работает без авторизации: сейчас используется один демонстрационный
> студент, поэтому его можно сразу запускать и проверять локально.

## Что внутри

| Раздел | Для чего нужен |
| --- | --- |
| **Темы** | Курс, отсортированный по порядку учебника и разделённый на 1-й и 2-й семестры |
| **Конспекты** | Определения, теоремы, критерии, свойства, примеры и полные доказательства |
| **Карточки** | Заучивание формулировок с быстрым повторением |
| **Формулировки** | Воспроизведение определения или теоремы по памяти |
| **Доказательства** | Игра «выбери правильную структуру доказательства» |
| **Устный тест** | Случайный вопрос с самооценкой ответа |
| **Теория** | Теоретический вариант по выбранному семестру |
| **ИКР** | Практические и исследовательские задания с полными решениями |
| **ТКР** | Варианты на доказательство, вывод формул и примеры |
| **Прогресс и топ** | История попыток и рейтинг по результатам |
| **Админка** | Добавление тем, материалов, карточек, вопросов и игр в базу |

Каждое задание связано с конкретной темой. Для ИКР и ТКР в базе хранятся
условие, ожидаемый ответ, тип задания и семестр; ответ можно раскрыть после
попытки и отметить результат.

## Быстрый запуск

### Вариант 1: Docker + Make

Нужны Docker с Compose, Go 1.25+ и Make.

```sh
docker compose up -d postgres
make run
```

После запуска откройте <http://localhost:8080>.

### Вариант 2: существующий PostgreSQL

Укажите строку подключения и запустите сервер:

```sh
export DATABASE_URL='postgres://user:password@localhost:5432/matan_trainer?sslmode=disable'
go run ./cmd/server
```

По умолчанию приложение использует:

```text
postgres://postgres:postgres@localhost:5544/matan_trainer?sslmode=disable
```

При первом старте сервер автоматически создаёт таблицы и загружает каталог
тем, теорию, карточки, вопросы и варианты. Повторный запуск идемпотентен: уже
сохранённые попытки не удаляются.

Остановить PostgreSQL:

```sh
docker compose down
```

Для удаления локального тома с базой данных используйте это только осознанно:

```sh
docker compose down -v
```

## Маршруты приложения

| URL | Экран |
| --- | --- |
| `/` | Обзор и счётчики наполнения |
| `/topics` | Все темы с якорями семестров |
| `/topic/{id}` | Конспект одной темы |
| `/cards` | Карточки формулировок |
| `/formulations` | Тренажёр воспроизведения формулировок |
| `/proof-game` | Игра с вариантами структуры доказательства |
| `/oral` | Устный тест |
| `/variant` | Смешанный письменный вариант |
| `/theory-test` | Тест по теории |
| `/ikr` | Вариант ИКР |
| `/tkr` | Вариант ТКР |
| `/progress` | Прогресс и история попыток |
| `/leaderboard` | Топ по результатам |
| `/admin` | Управление наполнением базы |

Для вариантов доступны фильтры:

```text
/variant?semester=1
/theory-test?semester=2
/ikr?semester=1
/tkr?semester=2
```

Параметр `semester=0` означает все темы.

## Структура проекта

```text
.
├── cmd/server/
│   ├── main.go              HTTP-сервер, маршруты и работа с ответами
│   ├── schema.go            схема PostgreSQL и базовый каталог курса
│   ├── curated_tasks.go     содержательные задачи ИКР/ТКР и порядок тем
│   ├── *_test.go             тесты бизнес-логики и покрытия каталога
│   ├── templates/            HTML-шаблоны
│   └── static/               CSS и JavaScript
├── cmd/pdfextract/          извлечение текста из учебников
├── docker-compose.yml        PostgreSQL 16
├── Makefile                  команды запуска и проверки
├── Levakov1.pdf             источник материалов курса
└── учебник.pdf              источник материалов курса
```

Учебники лежат в репозитории как исходные материалы. Утилита извлечения текста
печатает страницы в stdout:

```sh
go run ./cmd/pdfextract Levakov1.pdf
go run ./cmd/pdfextract учебник.pdf
```

## Команды разработчика

```sh
# Запустить сервер
make run

# Запустить все тесты
make test

# Проверить стиль diff и статический анализ
git diff --check
GOCACHE=/private/tmp/matan-go-build go vet ./...

# Собрать все пакеты
GOCACHE=/private/tmp/matan-go-build go build ./...

# Обновить зависимости
make tidy
```

Для команд Go можно использовать обычный `GOCACHE`; значение в примерах лишь
помогает не засорять рабочее дерево артефактами сборки.

## Модель данных

Основные сущности хранятся в PostgreSQL:

- `topics` — тема, глава, семестр и порядок в курсе;
- `theory_items` — определения, теоремы, критерии, примеры и доказательства;
- `cards` — лицевая и обратная стороны карточки;
- `questions` — задачи ИКР, ТКР, теории и устного теста;
- `proof_choice_games` — варианты выбора структуры доказательства;
- `attempts` — оценённые попытки демонстрационного студента;
- `exam_blueprints` — сохранённые шаблоны вариантов.

Кураторские материалы помечены источником `curated`, поэтому старые записи и
попытки не ломают обновление базы. Новый контент можно добавлять через
`/admin` или расширением seed-данных в `cmd/server`.
